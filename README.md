# 有人车—多无人机协同前出侦察 · 注意力分配实验原型

独立运行的 React + TypeScript + React Router + Vite 网页应用。首页只集中展示入口与条件配置；训练和正式实验在各自路由中进行。当前阶段保留完整页面框架和控件，实验刺激与结果指标仍为占位。

## 安装与本地启动

需要 Node.js 20.19+ 或 22.12+。在项目目录执行：

```bash
npm install
npm run dev
```

终端会显示本地地址，在普通浏览器中打开即可。应用不依赖 ChatGPT 界面或其专用 API。

## 生产构建

```bash
npm run build
npm run preview
```

构建输出位于 `dist/`。部署到普通静态 Web 服务时，应将未知路径回退到 `index.html`，这样直接打开或刷新独立实验路由仍可访问。当前 Sites 配置已启用单页应用回退。

## 路由

| 路径 | 页面 |
| --- | --- |
| `/` | 实验首页：总览、预实验入口、正式条件配置、结果导出 |
| `/pretest/main-task` | PT-01 主任务预实验 |
| `/pretest/sub-task` | PT-02 次任务预实验 |
| `/pretest/combined-task` | PT-03 主次任务组合预实验 |
| `/pretest/support` | PT-04 注意再分配支持预实验 |
| `/formal/run` | 独立正式实验运行页 |

首页不以弹窗、抽屉、局部展开或 iframe 执行实验。所有“进入”操作都通过 React Router 跳转。

## 数据保存

被试编号、预实验状态与参数配置、正式条件和模拟正式结果暂存于**当前浏览器的 `localStorage`**，键为 `attention-platform-single-page-v1`。预实验只保存配置与模块状态，绝不写入正式实验结果。正式实验运行页点击“完成模拟实验”后，才会新增一条模拟正式记录；首页仅导出当前被试的正式记录。CSV 每行一个模拟 trial。

浏览器数据不是正式研究数据：清理站点数据、更换浏览器或设备会失去这些本地记录。真实刺激、采集、指标计算及正式持久化尚未实现。
