# 有人车—多无人机协同前出侦察 · 注意力分配实验原型

独立运行的 React + TypeScript + React Router + Vite 网页应用。首页集中展示入口与条件配置；实验在独立路由中进行。第二阶段已实现 PT-01 动态目标跟踪训练和 PT-02 UAV 任务冲突判读训练。PT-03、PT-04 与正式实验仍为第一阶段框架。

## 安装与本地启动

需要 Node.js 20.19+ 或 22.12+。在项目目录执行：

```bash
npm install
npm run dev
```

终端会显示本地地址，在普通浏览器中打开即可。应用不依赖 ChatGPT 界面或其专用 API。

## 生产构建

```bash
npm run build
npm run preview
```

构建输出位于 `dist/`。部署到普通静态 Web 服务时，应将未知路径回退到 `index.html`，这样直接打开或刷新独立实验路由仍可访问。当前 Sites 配置已启用单页应用回退。

## 路由

| 路径 | 页面 |
| --- | --- |
| `/` | 实验首页：总览、预实验入口、正式条件配置、结果导出 |
| `/pretest/main-task` | PT-01 主任务预实验 |
| `/pretest/sub-task` | PT-02 次任务预实验 |
| `/pretest/combined-task` | PT-03 主次任务组合预实验 |
| `/pretest/support` | PT-04 注意再分配支持预实验 |
| `/formal/run` | 独立正式实验运行页 |

首页不以弹窗、抽屉、局部展开或 iframe 执行实验。所有“进入”操作都通过 React Router 跳转。

## 数据保存

被试编号、预实验进度状态、正式条件和模拟正式结果暂存于**当前浏览器的 `localStorage`**，键为 `attention-platform-single-page-v1`。PT-01 与 PT-02 的可调参数、每轮答案和反馈仅在当前页面会话中使用；只有训练完成状态会保存到首页。预实验数据绝不写入正式实验结果。正式实验运行页仍是第一阶段模拟框架，只有点击“完成模拟实验”才会新增一条模拟正式记录；首页仅导出当前被试的正式记录。

## 第二阶段训练

- PT-01：默认 10 个动态目标、4 个重点目标；5 秒准备、5 秒高亮、30 秒跟踪，结束后选择目标并查看训练反馈。运动引擎使用可编辑随机种子，支持暂停、继续、重置和下一轮。
- PT-02：默认 3 个候选方案、5 项指标、每题 8 秒、5 道中等难度题。题库独立存放，支持倒计时、超时、反馈、暂停和下一题。
- 训练算法与 UI 分离，相关模块位于 `src/pretests/`。数据与正式实验记录隔离。

使用 Node.js 24 可运行核心逻辑检查：`npm test`。

浏览器数据不是正式研究数据：清理站点数据、更换浏览器或设备会失去这些本地记录。真实刺激、采集、指标计算及正式持久化尚未实现。
